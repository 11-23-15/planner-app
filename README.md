# День — планировщик задач

Адаптивный планировщик на русском языке: ежедневные задачи, приоритеты и прогресс дня. Данные синхронизируются через Supabase и изолированы по аккаунтам.

## Локальный запуск

1. Установи зависимости: `npm install`.
2. Скопируй `.env.example` в `.env` и заполни URL проекта Supabase и публичный ключ.
3. Выполни `supabase/schema.sql` в SQL Editor своего проекта Supabase.
4. Запусти `npm run dev`.

Пока Supabase не настроен, приложение покажет экран настройки и не сохранит задачи локально.

## Безопасность

- Не добавляй `.env` и секретные ключи в Git.
- В браузере используется только publishable key.
- В таблице `tasks` включён Row Level Security; доступ разрешён только владельцу каждой строки.

## Публикация

Публикация сайта отдельно не настроена и требует отдельного согласования.
